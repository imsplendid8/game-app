# Claude Code 구현용 — 김넵 10개 질문 시나리오 확정 초안

> 목적: Claude Code가 재개되면 바로 `src/data/questions.ts`에 옮길 수 있도록, 1차 버전의 질문을 **정확히 10개**로 줄이고 각 질문의 상황·선택지·결과 방향을 구체화한다.  
> 상태: 사용자가 검토하며 수정·삭제·대체 제안을 하기 위한 초안이다.  
> 중요: 질문 수는 10개, 선택지는 질문마다 3개로 고정한다.

## 1. 전체 톤

- 참고 이미지의 핵심은 “내가 판교에 갈 상인가”식 테스트 화면, 일부 단어만 민트색으로 하이라이트된 판교어 해석 문제, “세커티/디벨롭/매리지체크/리셀/이슈 메컵/락앤”처럼 한국어와 영어가 뒤섞인 과장된 업무어, 그리고 “이 바닥 우습게 보면 대화도 못 하거든요~” 같은 장난스러운 후폭풍이다.
- 게임은 직장 예절 시험이 아니라 **메신저를 열 때마다 작은 재난이 튀어나오는 선택형 시트콤**이어야 한다.
- 모든 상황은 가상이며 실제 회사명, 실명, 특정 서비스명은 쓰지 않는다.
- `판교어`, `테크노밸리언 테스트`, `입력 중…`, `읽음 1`, `최종_진짜최종`, `17:47`, `48MB`, `네/넵/앗 네`, `취지는 좋지만`, `리소스가 타이트`, `가능 범위 재확인` 같은 디지털 직장 디테일을 적극 사용한다.
- 조롱 대상은 사람이 아니라 “애매한 말과 시스템”이다.

## 2. 데이터 작성 공통 규칙

- 질문 수: 정확히 10개
- 하루 구성: 5일 × 하루 2개 질문
- 선택지 수: 질문마다 정확히 3개
- 능력치: `sense`, `work`, `mental`, `favor`, `leave`
- 선택 결과 라벨: `센스`, `무난`, `아찔`
- 변화량 범위: 능력치별 -10~+10
- 최선 답변이 항상 가장 긴 문장이 되지 않게 한다.
- 버튼 문구는 모바일에서 1~2줄 안에 읽히도록 짧게 쓴다.
